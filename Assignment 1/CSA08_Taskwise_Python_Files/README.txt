CSA08 Assignment 1 - Task-wise Python files

Files
- Task01/task01.py through Task12/task12.py: separate executable demonstrations for each task.
- milkrate.py: shared milk-rate calculation module used by Tasks 04-09, 11 and 12.

How to run
1. Extract this ZIP completely.
2. Open the extracted CSA08_Taskwise_Python_Files folder in VS Code.
3. Open a terminal in that folder.
4. Run a task, for example: python Task04/task04.py
5. Run the main module tests: python milkrate.py

Important
Keep milkrate.py in the main folder. The task files import it by module name.
Task 01 is a data-design demonstration; Tasks 02-12 provide executable examples.
Python 3.10+ recommended. No third-party packages are required.
